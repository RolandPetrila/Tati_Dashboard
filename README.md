# Tati_Dashboard

Dashboard medical criptat AES-256 (StatiCrypt), servit pe GitHub Pages.

URL: https://rolandpetrila.github.io/Tati_Dashboard/

Conținut: HTML cifrat. Acces protejat cu parolă (cunoscută doar de Roland și familia restrânsă). Sursa clear-text rămâne în repo privat separat.

## Update workflow

Modificările se propagă din repo-ul sursă privat prin `scripts/encrypt_and_publish.py` (StatiCrypt CLI + git push automat).
